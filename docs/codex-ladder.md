# 八关：用这个项目练熟 Codex

每一关都对应 Codex 的一个真实能力，做完能在仓库里留下痕迹。页面上的「关卡」页有同样的内容，并且可以直接复制提示词。

建议节奏：一天一关，每关做完跑一次 `node scripts/validate-data.mjs`，然后提交一次 git。

## 第 1 关：让仪表盘说你的语言

**练什么**：仓库约定、`AGENTS.md`、数据契约。

改 `profile.goals` 里的目标值，再重建内联数据。你会第一次体会到「改文件 → 跑命令 → 页面变化」这条闭环。

```
打开 data/dashboard.json，把 profile.goals 改成我的真实目标：每天阅读 30 分钟、每周跑步 20 公里、每月预算 6000 元、每周咖啡不超过 8 杯。改完运行 node scripts/build-inline.mjs 和 node scripts/validate-data.mjs，并告诉我哪些指标会因此变化。
```

## 第 2 关：把随手记变成固定流程

**练什么**：Skill，以及「把重复劳动写成可复用流程」。

仓库里的 `skills/life-dashboard/SKILL.md` 已经写好一套录入流程。先直接用，再改一处你觉得别扭的地方。

```
读 skills/life-dashboard/SKILL.md，然后按里面的流程帮我录入今天的记录：跑步 5 公里 32 分钟，午餐花费 38 元，咖啡 1 杯手冲。录完运行两个脚本并汇报结果。
```

## 第 3 关：给数据加一条底线

**练什么**：测试、失败用例、验收标准。

先让校验失败，再修好它。顺序很重要，能看到「红灯变绿灯」你才算真的验证过。

```
给 scripts/validate-data.mjs 增加一条规则：任何一次咖啡消费的 cost 不能超过 80 元。先故意在 data/dashboard.json 里造一条超标数据，让我看到校验失败的样子，再删掉它并确认校验通过。
```

## 第 4 关：开两个子代理写周报

**练什么**：子代理分工、并行、结果合并，以及「什么时候不该并行」。

让一个子代理只做统计，另一个只写文字，最后由主代理合并。注意要求它们不要互相改文件。

```
用两个子代理并行处理：一个读 data/dashboard.json 统计我上周的阅读、跑步、支出和咖啡数据，只回统计数据；另一个根据统计数据写一份不超过 300 字的中文周报，只回正文。最后你把两者合并，附上关键数字，并把周报存到 issues/ 目录。
```

## 第 5 关：每天自动播报

**练什么**：自动化、通知策略、长期运行的任务。

让 Codex 建一个每天 21:30 的自动化。重点是「只在异常时打扰我」。

```
创建一个每天 21:30 运行的自动化：读取 data/dashboard.json 里今天的记录，生成一句不超过 60 字的今日总结，追加到 data/dashboard.json 的 journal 数组里，并运行校验。只有生成失败或数据缺失时才通知我，一切正常就不要打扰。
```

## 第 6 关：接一个真实数据源

**练什么**：MCP 与连接器、私有数据边界、导入脚本。

拿一份真实的账单 CSV、运动 App 导出或日历数据，替换掉一部分手工录入。让 Codex 先讲清楚它需要什么字段，再动手。

```
我有一份账单导出的 CSV（列名我先贴给你）。先告诉我应该放在哪个目录、需要哪些字段、重复记录怎么判重，然后再写导入脚本合并进 data/dashboard.json，保证 node scripts/validate-data.mjs 通过。
```

## 第 7 关：守住数据底线

**练什么**：Hook 与机械约束。

约定靠提示词，底线靠 hook。让 Codex 先查官方文档确认当前的 hook 配置格式，再写进 `.codex/config.toml`。

```
先查一下 Codex 官方文档里 hook 的配置格式，确认当前版本怎么写。然后帮我在 .codex/config.toml 里配一个 hook：只要 data/ 目录下的文件被修改，就自动运行 node scripts/validate-data.mjs。配好以后故意改坏一条数据，验证 hook 真的能拦住我。
```

## 第 8 关：装进手机主屏

**练什么**：Manifest、Service Worker、部署到 HTTPS。

前七关都在电脑上，这一关把它变成手机上的 App。做完之后你会知道 PWA 为什么需要 HTTPS，以及缓存为什么会让改动"看不见"。

```
把这个项目部署到一个 HTTPS 地址（GitHub Pages 或 Vercel），部署完告诉我用 iPhone Safari 添加到主屏的步骤。然后教我验证离线可用：手机先联网打开一次，再开飞行模式打开，确认还能看到页面。如果我改了代码但手机上还是旧版，告诉我怎么升 sw.js 里的缓存版本号。
```

从主屏图标长按还有「记一笔」和「今日复盘」两个快捷入口，这是 `manifest.webmanifest` 里 `shortcuts` 的功劳。

## 通关之后

把示例数据换成你自己的记录。到那时这个仓库就不再是练习场，而是你每天真的会打开的仪表盘。

后面可以继续做的方向：

- 增加 `issues/` 周报归档与页面入口。
- 把传统脚本迁移到 ES module，并加一个本地静态服务器。
- 给图表加时间范围切换（7 / 30 / 90 天）。
- 接入真实数据源后，把 `scripts/generate-data.mjs` 从生成器改成导入器。
